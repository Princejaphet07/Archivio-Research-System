# ⚡ ARCHIVIO Quick Start Testing Guide

## 1. Local URLs
- **Unified Academic Portal:** `http://localhost:5173`
- **Public Research Archive:** `http://localhost:5174`
- **Interactive REST API Docs:** `http://localhost:3001/docs` (or `https://archivio-research-system.web.app/docs`)

## 2. Default Test Roles
- **Student:** Login at `http://localhost:5173` (redirects to `/student`)
- **Adviser:** Login at `http://localhost:5173` (redirects to `/adviser`)
- **Dean:** Login at `http://localhost:5173` (redirects to `/dean`)
- **Admin:** Login at `http://localhost:5173` (redirects to `/admin`)

## 3. Production Cloud URLs
- Unified System: [https://archivio-research-system.web.app](https://archivio-research-system.web.app)
